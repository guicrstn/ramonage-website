Comment l'installer dans Outlook

Outlook (application bureau) :
  1. Selectionnez la signature ci-dessus (du logo jusqu'au bouton rouge) et copiez-la avec Ctrl+C.
  2. Dans Outlook : Fichier → Options → Courrier → Signatures...
  3. Cliquez sur Nouveau, donnez un nom (ex : "LB Ramonage"), collez avec Ctrl+V dans la zone d'edition.
  4. Choisissez cette signature par defaut pour les Nouveaux messages et les Reponses/transferts, puis OK.
Outlook sur le web (outlook.com / Microsoft 365) :
  1. Copiez la signature ci-dessus (Ctrl+C).
  2. Cliquez sur l'engrenage Parametres → Courrier → Composer et repondre.
  3. Collez dans la zone Signature electronique, activez-la par defaut, puis Enregistrer.

Important : pour que le logo s'affiche chez vos destinataires, votre site lbramonage.fr doit etre en ligne (l'image est chargee depuis lbramonage.fr/signature/logo-signature.png). Si vous n'avez pas encore de nom de domaine, dites-le moi et j'adapterai l'adresse de l'image.
